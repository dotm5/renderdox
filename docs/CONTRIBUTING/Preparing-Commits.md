# Recording RenderDox changes

[Development notes](../CONTRIBUTING.md) · [Project showcase](../../README.md)

Commits record the intent and result of an experiment. A short summary and an explanation
of a non-obvious change make it easier to revisit the work later.

The project has no commit-title length gate, prescribed squash/rebase procedure or PR
format check. Merge commits can record upstream integration; ordinary commits can record
local experiments and features.

Formatting tools are available in `util/clangformat` for convenience. Existing core code
can serve as a style reference when keeping a diff easy to compare. The project does not
require a particular formatter version or formatting every intermediate commit.
