# Suggesting a RenderDox experiment

[Issues and ideas](Filing-Issues.md) · [Project showcase](../../README.md)

Describe the idea or workflow you want to explore. A proposed implementation, example
capture, screenshot or reference project can provide context when available.

Target-specific features, unusual capture paths, custom hooks, managed runtimes and
LLM tooling are valid directions for this personal project. Experiments do not need to
serve a broad audience or support every graphics API before being considered.

Ideas can be discussed in the [RenderDox issue tracker](https://github.com/dotm5/renderdox/issues).
