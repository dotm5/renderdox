About this project
------------------

RenderDox is a personal RenderDoc derivative for Windows graphics capture, replay,
custom capture integrations, desktop improvements and LLM-assisted investigation.
Its runtime and desktop application use the DComp identity.

The project is planned and maintained independently. Custom hooks, proxy loaders,
managed-host adapters and target-specific experiments are part of its development scope.

Documentation
-------------

The `project showcase <https://github.com/dotm5/renderdox>`_ introduces the features.
The `usage guide <https://github.com/dotm5/renderdox/blob/dgcore-main/USAGE.md>`_
explains portable setup, capture activation and MCP configuration.

The :doc:`getting_started/quick_start`, desktop window references and :doc:`how/index`
cover native capture and replay concepts. :doc:`getting_started/gotchas_known_issues`
describes behavior relevant when investigating a capture.

Downloads and questions
----------------------

Windows packages are available from `RenderDox releases <https://github.com/dotm5/renderdox/releases>`_.
Questions, findings and ideas belong in the `RenderDox issue tracker <https://github.com/dotm5/renderdox/issues>`_.
