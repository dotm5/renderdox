# Developing RenderDox

[Project showcase](../README.md) · [Usage guide](../USAGE.md)

RenderDox is a personal graphics-tooling project planned and maintained by one developer.
Experiments, target-specific integrations, custom hooks, proxy loaders, managed-host adapters,
UI changes and LLM-assisted development are all part of its scope.

Issues can be used for questions, ideas, findings or bugs. Pull requests, including drafts,
can share work at any stage. Templates and development notes are optional aids.
Development decisions are made within this project.
