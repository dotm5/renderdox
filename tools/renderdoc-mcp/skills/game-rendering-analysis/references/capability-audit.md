# 能力边界与验收状态

历史实测基线：2026-10-01，0.3.1 的两帧 D3D11 角色捕获，44 种工具被直接调用。
状态核对日期：2026-10-22。当前服务为 0.3.2、72 个工具，已发布双语分析文档入口和嵌套 capture 附件修复。
下文的 44 种工具记录该历史案例的实测范围；各 backend/Shader/场景按实际能力与运行结果选择。

## 已有并在该案例实测

绘制证据、几何候选归组、纹理和通道预览、原始纹理/缓冲读取、post-VS 网格、像素历史、所选绘制输出贡献、资源流、有限深度依赖图、Vertex/Pixel 调试、轨迹查询及受限比较、跨帧资源匹配/事件对齐/常量变化、D3D11 内置计数器、交互性能 HTML、注释、离线证据包和 Capture Doctor 的证据分级。

这些能力足够让 LLM 推进多数文章的取数、算法调查和配图。是否能回答某具体算法仍取决于捕获状态、信息覆盖和 backend 支持。

## 有接口，但不能直接算作该角色的实机验收

- `replace_shader`/`restore_replacement`：已有目标 Shader 编译、安装与恢复实现；本案例没有验收完整材质重建基线、内部量输出和效果开关实验。
- Compute debug 及其他 API：不能从本次 D3D11 Vertex/Pixel 成功推出完整支持。
- D3D12 创建顺序样例属于独立样例，不能证明这个 D3D11 游戏的对象包装状态。

## 尚无内置通用功能

- 自动恢复原始 HLSL、语义变量名、纹理通道名或整个 Shader 效果图。
- 给任意 DXBC 自动插桩并输出任意中间寄存器的全帧图。
- 一条命令编排重建基线、多个参数/效果变体、数值等效校验和完整恢复证据。
- 用图像自动确认“皮肤/水滴/丝袜”等语义；归组工具给出证据候选，由 LLM 解释。
- 通用 cbuffer 参数覆写，以及将宿主生成的 HLSL/解释图直接注册到 MCP 证据包的工具。
- 自动作图和撰写文章：由 LLM 与宿主文件/绘图工具承担，skill 给出方法与格式。

## 已知限制

- DXBC Unknown 类型的常量/寄存器 raw union 使同一 Pixel 轨迹的自比较也可能 incomplete；保持保守结果，不伪造完整等价证明。
- 依赖图可能 truncated，属于资源级读写记录；截图是显示预览，真实数值要读 raw/pixel。
- 本帧没有原生 Pass marker ancestry；不存在的树层级不能补成引擎证据。
- Nsight Perf SDK 缺失项是错误占位，不是计数器；现有 GPU 时间来自回放。
- 0.3.1 的捕获元数据附件遗漏已在 0.3.2 修复；当前便携构建包含修正后的导出器，`test_bundle_includes_nested_capture_artifacts` 持续覆盖该路径。

结论：**原始数据分析链路较完整，文章级效果实验还未完全验收。** LLM 能用现有接口手动完成一部分回放重建和输出；skill 不能补出缺失数据或把未运行接口变成已验收能力。
