# 离线回放实验

这里提供可复现实验结构；LLM 根据具体 Shader 构建代码，不假设 MCP 自动理解材质。

## 基线与作用域

1. 在保存的 RDC 上使用独立 replay session，记录捕获哈希、EID、Shader 哈希及所有输出，保持原捕获不变。
2. 保存原始结果。若需要重建 HLSL，保留输入签名、资源类型和绑定、采样器、常量布局、输出签名、MRT、discard/深度语义及必要的导数/LOD 行为。
3. 用 `replace_shader` 编译并安装，检查 `installed` 和 diagnostics。替换按 Shader resource 生效，不只针对提交的 EID；找出共享这个 Shader 的绘制。
4. 重建版本先不改变效果，与原始结果做数值和视觉对比。既比较最终颜色，也比较被消费的相关 MRT，设置明确容差。只有编译成功不能称为等效重建。
5. 基线达标后才修改一个条件/计算项，或将一个中间量写到选定输出。保持其他输出契约；如果改变布局/精度/混合/早深度等，记录实验偏差。

## 实验类型

| 类型 | 用途 | 解释限制 |
|---|---|---|
| 禁用完整绘制 | 查描边、贴花、附加网格贡献 | 不说明同一 Shader 内部叠加项 |
| 禁用内部项 | 关闭湿润法线、粗糙度调制、高光等 | 必须先有合格的重建/可修改代码基线 |
| 输出内部量 | 湿度、法线、阈值、AO、采样 UV | 明确显示编码，不能把编码后的 PNG 当原数值 |
| 参数扫描 | 检查阈值、宽度、强度或光向敏感性 | 参数替换要能定位到真实输入；不假设有通用 cbuffer 修改工具 |
| 跨帧比较 | 干湿/时间/姿态/视角 | 控制其他变量，确保匹配对象和渲染分支；不能假定连续采样 |

当前 MCP 没有通用基线/变体结果比较编排工具。LLM 可用宿主脚本依次调用现有工具，在不同 session 或恢复前后导出 `read_texture` 原值，用宿主数值工具比较。`diff_shader_traces` 仅支持同字节码的受支持轨迹，不用于证明修改后 Shader 的等价性。

## 实验记录

记录假设、具体代码改动、Shader 绑定及共享范围、编译结果、基线误差、相同 ROI 的输入与输出、阈值和数值差分、是否恢复。保留 raw 纹理供核查；图中并排原始、实验、差分，标注捕获和绘制。

在 finally 中调用 `restore_replacement`；最好每个独立变体使用独立 session，并在结束时 `close_capture`。不要在有活动替换的 session 中把结果解释为原始游戏输出。实验失败时仍恢复，然后保留诊断与未验证状态，不用重新抓取整个场景掩盖失败。

## 雨痕的最小调查

- 输入：湿度来源、世界高度/水位影响、时间、滚动 UV、雨痕及表面控制纹理、光照/视角。
- 通路：覆盖和流痕 → 法线混合 → AO/粗糙度 → 反射/MatCap/高光 → 合成。只写有证据的通路。
- 对照：原始；整个湿润分支关闭；仅法线不变；仅粗糙度不变；仅水滴高光关闭；必要的中间量。
- 变更某项使画面改变只是对该项有贡献的证据；没有改变还需检查分支、遮罩、遮挡和显示映射。
- 未执行的天气分支需要适当状态捕获或可说明限制的回放修改，不能直接当成实测湿润效果。
