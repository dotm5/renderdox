## 已集成的修复

| 项 | 当前结果 | 说明 |
| --- | --- | --- |
| D3D12GetInterface provider | 排除私有 D3D12Core provider | 公开 d3d12.dll 入口保持其公开契约 |
| 公开 DeviceFactory root | 已接入现有 DeviceFactory wrapper | 使用公开 CLSID_D3D12DeviceFactory 路径 |
| DXGI parent factory | 相同 native identity 复用 factory wrapper | 弱缓存查找与退休重建共用同步机制 |
| SwapChain.GetDevice | 返回匹配的 device wrapper | IUnknown/typed 返回维护 canonical identity 与引用计数 |

## 历史测量

七组正向矩阵共记录 28 份 capture/replay，覆盖 system、second、resize、Agility、
Core preload、Agility second 和 direct DeviceFactory。诊断开/关的对应指纹一致。
样例验证 GetDevice typed/IUnknown identity、64 次返回后的引用计数，以及通过返回
device 创建队列、录制并提交工作。第二设备使用独立 WARP device/queue。

UE 样例另有 3 次 A、2 次 B 的历史记录，均完成捕获和回放；选定 36 个 draw 的参数、
Shader 字节和输出纹理指纹一致。B2 的 dependency/texture 数量超出该组 A/A 观测范围。
这些测量保留其当时构建和样本范围。

## 当前默认策略

保留默认 loader/IAT 与 System32 DXGI hook 覆盖。诊断及 A/B 开关继续显式启用；
该组结构化摘要保留观测到的差异，未作为删除默认 hook 的验收。
当前源码包含上表修复，正常 Release 的 closure 诊断默认关闭。
